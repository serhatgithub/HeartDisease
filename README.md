# Heart Disease Prediction

This project uses machine learning to predict the presence of heart disease based on medical attributes. The dataset is derived from the [UCI Heart Disease dataset](https://archive.ics.uci.edu/ml/datasets/heart+Disease).

## Project Features

- Data analysis & preprocessing
- Model training (classification)
- Evaluation using accuracy, precision, recall, F1-score

## Technologies

- Python 3.x
- Jupyter Notebook
- pandas, numpy, matplotlib, seaborn
- scikit-learn

## Dataset Features

- Age, Sex, Chest Pain Type
- Resting BP, Cholesterol, Fasting Blood Sugar
- ECG Results, Max Heart Rate
- Exercise-induced Angina, Oldpeak, Slope, Vessels, Thalassemia
- Target: 0 = No Heart Disease, 1 = Heart Disease

## Evaluation Metrics

- Accuracy
- Confusion Matrix
- Precision, Recall, F1-score

## How to Use

1. Open the `Heart.ipynb` file in Jupyter Notebook
2. Run the cells in order
3. Observe predictions and metrics at the end
